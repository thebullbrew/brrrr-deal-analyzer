# BRRRR Deal Analyzer

Free web app for real-estate investors — run the full BRRRR loop (Buy → Rehab → Rent → Refinance → Repeat) and see exactly how much cash stays trapped in the deal.

**What it computes:** total cash invested, refinance proceeds (75% cash-out of ARV), cash left in the deal, monthly cash flow, cash-on-cash return (flags "infinite" at $0 left in), and DSCR — with a verdict banner from TRUE BRRRR to NOT A BRRRR.

**Stack:** static HTML/CSS/JS, no build step. Local-first via localStorage. Dark old-money theme.

**Live:** https://thebullbrew.github.io/brrrr-deal-analyzer/
